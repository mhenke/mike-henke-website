I have been following an interesting conversation on the CFEclipse user group, "<a href="http://groups.google.com/group/cfeclipse-users/t/6c3312fa147820cb" target="_self">File Explorer issues, again</a>". It started about the File Explorer view not working in CFEclipse (Mark Drew has released a <a href="http://www.markdrew.co.uk/blog/index.cfm/2007/11/9/CFEclipse-1316-Released" target="_self">fix</a>). Eclipse forces a project approach. Some people find the transition difficult. Dreamweaver users should be familiar with the project focus. It is similiar to <a href="http://kb.adobe.com/selfservice/viewContent.do?externalId=tn_14028&amp;sliceId=1" target="_self">defining a site</a> in DW. Main idea is use whatever editor you are most productive with. CFEclipse plugin has its quirks but I made the switch a couple years ago and won't go back to Dreamweaver.<br /><br />Toward the end of the conversation Stephen Davison mentioned <a href="http://www.eclipse.org/dsdp/tm/" target="_self">Remote Systems Explorer</a> (RSE) plug-in.
