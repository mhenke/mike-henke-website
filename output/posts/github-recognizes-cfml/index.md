<a href="http://www.github.com">Github</a> now tracks <a href="http://en.wikipedia.org/wiki/ColdFusion_Markup_Language">CFML</a> syntax. Github uses <a href="http://dev.pocoo.org/projects/pygments">Pygments</a>, a generic syntax highlighter.  Pygment recently added support for CFML and Github has implemented it.
<h3>What does this mean to the ColdFusion community?</h3>
Github recognizing ColdFusion means more <span class="kn"></span><span>exposure</span>. Currently<a href="http://github.com/languages/ColdFusion"> 
ColdFusion is the 32nd most popular language on Github</a>.  <a href="http://github.com/languages/PHP">PHP is the 7th</a>. I would love to 
see more of the ColdFusion community migrating open source projects 
to github.
Snapshot from <a href="http://github.com/rip747/cfwheels">http://github.com/rip747/cfwheels</a>

<h3>What is Git and Github?</h3>
"Git is a fast, efficient, distributed version control system ideal for the collaborative development of software.<br />GitHub is the easiest (and prettiest) way to participate in that collaboration: fork projects, send pull requests, monitor development, all with ease." - text from <a href="http://github.com">http://github.com</a>
<h3>What about Riaforge?</h3>
<a href="https://www.riaforge.org">Riaforge</a> should still be the centralized place to <span class="header01">find and showcase open source project built on Adobe technology but the source code and <a href="http://github.com/blog/411-github-issue-tracker">issue tracker should reside on Github</a>.  Similiar to projects using Google Code. <a href="https://cfgithub.riaforge.org/">CFGithub</a> is an example of a</span> Riaforge project using Github.
