<st1:place w:st="on">Lot</st1:place> of the CFEclipse users say use <a href="http://aptana.com/" target="_self">Aptana</a>. Clarification usually not provided with the generally helpful advice is Aptana doesn't open ColdFusion related file extension by default. <br /><br />Editors allow you to edit, save, and revert the editor&rsquo;s content. Editors have built-in language-specific knowledge. <em>Functionality of editors aren't combined. </em>Which editor is open is based on File Association set in Preferences by file extension (Preferences --&gt; General --&gt; Editors --&gt; File Associations). <img alt="File Association within Preferences" src="http://mikehenke.com/machblog/uploads/Image/fileassociations.jpg" />  Aptana has several editors along with multiple useful views. CFEclipse has one editor along with multiple useful views. Aptana editors can be used with files like html, htm, css, js, and xml not cfm related . <br /><br />The File association default is what editor will be used when opening the file. When right-clicking on the file then "Open With" you can see default and other associated file editors. It is possible to open the file with non-associated editors using Other. Multiple editors can be associated with a file extension and one editor set as the default editor but <em>only one editor will be used.</em><p class="MsoNormal">Take a look @ my snapshots of opening a cfm file with Aptana HTML editor verses CFEclipse editor.<br /><br />Notice the Aptana HTML editor <em>doesn't recognize the cf tags</em>. <p class="MsoNormal">Aptana HTML Editor with a cfm file:<br /><img alt="Aptana HTML Editor with cfm file" src="http://mikehenke.com/machblog/uploads/Image/aptanaHTML.jpg" /> The code insight is different and the color formatting schema is different.CFEclipse Editor with a cfm file:<br /><img alt="CFEclipse editor with cfm file" src="http://mikehenke.com/machblog/uploads/Image/cfeclipse.jpg" />This post is in regards to a discussion occuring @ CFEclipse User Group named <a href="http://groups.google.com/group/cfeclipse-users/browse_thread/thread/2b756673f546f7fe" target="_self">CFEclipse and HTML</a>.
