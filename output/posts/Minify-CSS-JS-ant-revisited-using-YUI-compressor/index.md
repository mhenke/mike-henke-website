I have revisited adding <a href="http://developer.yahoo.com/yui/compressor/">Yui compressor</a> into my work's ant build script to minify JS and CSS scripts. The current jar was yuicompressor-2.3.5.jar . It took a lot of playing around but I finally stumbled on how to get it to work. Here is the snippet for the yuicompressor. I had to jump through a couple hoops like overriding the current js/css scripts with the optimized js/css scripts. I'll release a <a href="http://mikehenke.com/machblog/uploads/enclosures/yuiCompressor2_3_5.zip">full working copy in a zip</a>, you can run against your webroot.
