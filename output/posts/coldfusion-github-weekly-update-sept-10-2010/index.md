Two weeks since the last <a href="http://www.adobe.com/products/coldfusion/">ColdFusion</a> &amp; <a href="http://www.github.com/">Github</a>. I will start with what I missed. A <a href="http://www.mangoblog.org/news/github-gists-plugin">Mango Blog plugin for gists</a> was announced Aug. 16th. You may be wondering what the heck are GISTS?<br /><br /><strong>Gist</strong> is a simple way to <strong>share snippets and pastes</strong> with others. All <strong>gists</strong> are git repositories, so they are automatically <strong>versioned</strong>, <strong>forkable</strong> and usable as a <strong>git repository</strong>.<br /><br />Pretty sweet huh? Now back to what has happened since the last update.

<h2>ColdFusion on Github Highlights</h2>
<div><a href="http://www.terrenceryan.com/">Terry Ryan</a> is keeping his releasing code on github streak going with <a href="http://www.terrenceryan.com/blog/post.cfm/coldfusion-from-a-console">CFConsole</a>. Round of applause for Terry, now people start forking and help the guy out :-) <a href="http://github.com/seancorfield/di1">DI/1 - Inject One</a> was added to Github during CFUnited but sparked some conversation about <a href="http://corfield.org/blog/post.cfm/open-source-rtw-or-collaboration">Reinventing the Wheels </a>vs Collaberating on existing projects. <a href="http://github.com/coldbox">ColdBox Platform</a> is on Github now. <a href="http://www.johncblandii.com/">John Blandii</a> has created a <a href="http://cookingwheels.com/">Cooking Wheels site</a> and the <a href="http://github.com/johncblandii/cookingwheels">source is on github.</a>  <a href="http://github.com/mhenke/litepost">LitePost</a>,  a lightweight CFML-based blog application built in various ColdFusion frameworks, is on github. Currently, <a href="https://fw1.riaforge.org/">FW/1</a>, <a href="http://cfwheels.org/">Wheels</a>, <a href="http://github.com/tonynelson19/ColdMVC">ColdMVC</a>, <a href="http://www.mach-ii.com/">MachII</a>, and <a href="http://model-glue.com/">Model-Glue</a> have examples. The MachII and Model-Glue examples need updated if anyone is interested in contributing.</div>
