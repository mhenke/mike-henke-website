I really enjoy <a href="http://en.wikipedia.org/wiki/ColdFusion">ColdFusion</a> but I am frustrated seeing tools in other programming languages like metric testing (<a href="http://www.ndepend.com/">NDepend</a>), code coverage (<a href="http://emma.sourceforge.net/">Emma</a>), and coding standards (<a href="http://checkstyle.sourceforge.net/">Checkstyle</a>). None of these tools are new. They are immensely helpful, but not really available in <a href="http://en.wikipedia.org/wiki/ColdFusion_Markup_Language">CFML</a>.That being said, I feel ColdFusion is several years behind everyone else. Look @ the recent Hibernate <a href="http://www.adobe.com/devnet/coldfusion/articles/coldfusion9_orm.html">addition to ColdFusion 9</a>. <a href="http://en.wikipedia.org/wiki/Hibernate_%28Java%29">Hibernate</a> actually won a <span class="mw-redirect">Jolt Award</span> in 2005 and has been around before that but now 2009 (really maybe 2010 depending on CF9 release) ColdFusion is incorporating it.Recently there was a successful push by the ColdFusion community towards source control. It seems <a href="https://en.wikipedia.org/wiki/Subversion_(software)">SVN</a> is now a defacto piece in most development shops. If not SVN, then some type of source control. I am hoping for a push by <a href="http://riaforge.org">RIAForge</a> and other ColdFusion community leaders to use <a href="http://en.wikipedia.org/wiki/Git_%28software%29">Git</a>.For the ColdFusion project community, I see Git as a way for stale projects to get re-energized and have more community members involved. Git might have been a good fit for <a href="wwhttp://www.fusebox.org/">Fusebox</a> so it didn't have to fork into a new project <a href="http://cfrant.blogspot.com/2009/08/fuseng-announced.html">FuseNG</a>. Users of Fusebox, could have seen the main Fusebox repository going dormant and noticed <a href="http://cfrant.blogspot.com">Adam Haskell</a> with alot of activity. FuseBox users then could start pulling from Adam. Fusebox could also eventually pull in Adam's changes or not.This is just one example but I hope to see ColdFusion ride the crest <del>of Git</del> instead of following in the wake.More information on Git: <a href="http://www.ibm.com/developerworks/web/library/wa-git/index.html">Git changes the game of distributed Web development</a>
