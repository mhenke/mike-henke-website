If you haven't heard of the <a href="https://varscoper.riaforge.org/ ">vaScoper tool</a> created and maintained by <a href="http://www.schierberl.com/cfblog/">Mike Schierberl</a>, it is definately worth checking out. It has the stamp of approval of <a href="http://www.coldfusionjedi.com/index.cfm/2008/5/22/VarScoper-Tool ">Raymond Camden</a> and <a href="http://corfield.org/blog/index.cfm/do/blog.entry/entry/varScoper_updated">Sean Corfield</a>.Here is a varScoper ant target recently added to the <a href="http://www.mxunit.org">MXUnit</a> build ant. Download both tools and give them a test drive. <em>&lt;target name="varScopeCheck" depends="init"&gt;<br /> &lt;!-- MUST HAVE VARSCOPER IN WEBROOT --&gt; <br /> &lt;echo&gt;Check for unscoped variables&lt;/echo&gt;<br /> &lt;!-- load the varScoper task --&gt;<br /> &lt;taskdef name="conGet" classname="com.varscoper.ant.task.ConditionalGet" classpathref="project.classpath" /&gt;<br /> <br /> &lt;property file="${antrunner.file}" /&gt;<br /> &lt;property name="filePathToUse" value="${webroot}"/&gt;<br /> &lt;property name="recursiveDirectory" value="true" /&gt;<br /> <br /> &lt;conGet dest="varScoper.csv" url="</em><a href="http://${server}:${port}/varscoper/varScoper.cfm"><em>http://${server}:${port}/varscoper/varScoper.cfm</em></a><em>" &gt;<br /> &lt;parameter name ="filePath" value="${filePathToUse}" /&gt;<br /> &lt;parameter name="displayFormat" value ="csv" /&gt;<br /> &lt;parameter name="recursiveDirectory" value = "${recursiveDirectory}" /&gt;<br /> <br /> &lt;!-- <br /> &lt;FailIfNotFound pattern="&amp;lt;results&amp;gt;&amp;lt;/results&amp;gt;" /&gt;<br /> &lt;FailIfFound pattern=".cfc" message="var scope violation is found." /&gt;<br /> &lt;FailIfFound pattern=".cfm" message="var scope violation is found." /&gt;<br /> --&gt;<br /> &lt;/conGet&gt;<br /> <br /> &lt;!-- check csv file for any violations --&gt;<br /> &lt;loadfile srcfile="varScoper.csv" property="varScoper.cvs"&gt; <br /> &lt;filterchain&gt; <br /> &lt;headfilter skip="1"/&gt; <br /> &lt;trim/&gt; <br /> &lt;/filterchain&gt; <br /> &lt;/loadfile&gt; <br /> <br /> &lt;!-- will be set if violations found else variable will be unset --&gt;<br /> &lt;echo&gt;${varScoper.cvs}&lt;/echo&gt; <br /> <br /> &lt;fail message="var scope violation is found."&gt; <br /> &lt;condition&gt; <br /> &lt;isset property="varScoper.cvs"/&gt;<br /> &lt;/condition&gt; <br /> &lt;/fail&gt;<br /> <br /> &lt;echo&gt;Successful check for unscoped variables&lt;/echo&gt;<br /> &lt;/target&gt;</em>
