After a lot of trial and error tonight, I am able to start and stop my ColdFusion server from Eclipse. I am working with Ubuntu, CF8, and JRun along with Eclipse 3.3.1.1, your environment may need tweaking.<img width="297" height="279" src="/machblog/uploads/Image/run.jpg" alt="" /><br /><br />Before I basically ran "sudo /opt/jrun4/bin/jrun start cfusion" in a terminal to start CF even though I have created startup scripts.<h3>Creating a project for the jrun folder</h3>First I created a new project using "Java Project". I named it jrun and selected "Create project from existing source" then put "/opt/jrun4" in the directory field. Then I created the start and stop items.<h3>Start ColdFusion JRun server in Eclipse</h3><em>Run --&gt; Open Run Dialog</em> then right-click on <em>Java Application</em> and select <em>new.</em><p align="left"><u><strong> Main tab</strong></u><br />Name: JRun -start cfusion<br />Project: jrun<br />Main class: jrunx.kernel.JRun<img width="962" height="666" alt="" src="/machblog/uploads/Image/main.jpg" /> <div align="left"><u><strong>Arguments tab</strong></u><br />Program arguments: start cfusion<br /><br />VM arguments: -Xms512m -Xmx512m -XX:PermSize=128m -XX:MaxPermSize=128m -Dsun.io.useCanonCaches=false -Djmx.invoke.getters=true<img width="962" height="666" src="/machblog/uploads/Image/arg.jpg" alt="" /></div><strong> Common tab</strong><br />I also decided to display in favorites menu for easy access.<h3>Stopping ColdFusion JRun server with Eclipse</h3>I duplicated the starting instance. Changed the name to "JRun -stop cfusion" on the Main tab. In the Arguments tab, I changed start to stop in the Program arguments section and removed the VM arguments.My resources:<br /><br /><a href="https://help.ubuntu.com/community/PHPEclipse"> https://help.ubuntu.com/community/PHPEclipse</a><br /><a href="http://livedocs.adobe.com/jrun/4/Getting_Started_with_JRun/intro6.htm"> http://livedocs.adobe.com/jrun/4/Getting_Started_with_JRun/intro6.htm</a><br /><a href="http://barefootdevelopment.blogspot.com/2006/05/debugging-j2ee-technology-apps-on-jrun.html">http://barefootdevelopment.blogspot.com/2006/05/debugging-j2ee-technology-apps-on-jrun.html</a><br /><a href="http://www.myeclipseide.com/PNphpBB2-printview-t-9805-start-0.html"> http://www.myeclipseide.com/PNphpBB2-printview-t-9805-start-0.html</a><br /><br /><em> Later I will show how I setup a feature of PHPEclipse to start, stop, and restart my apache server.</em>
