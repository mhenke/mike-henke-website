This expands on my<a target="_self" href="http://mikehenke.com/machblog/index.cfm?event=showEntry&amp;entryId=055A6924-188B-4E84-1534BBFD052A04CA"> first entry of using sql results from ant</a> to do other ant process with sql results. This Ant script will store SQL results as an XML file and extracting the values using two different techniques, <a target="_self" href="http://ant.apache.org/manual/CoreTasks/xmlproperty.html">xmlproperty</a> and <a target="_self" href="http://www.oopsconsultancy.com/software/xmltask/">xmltask</a>. I use a <em>for </em>loop which comes from <a target="_self" href="http://sourceforge.net/projects/ant-contrib/">Ant-Contrib</a>. Ant-Contrib is a complilation of <a target="_self" href="http://ant-contrib.sourceforge.net/ant-contrib/manual/tasks/index.html">several tasks and types</a>.<em>This code assumes you have ant setup with sql and using MSSQL with Northwind. It will work with other databases as long as you can produce well-formed xml. For convience I included the jars for ant-contrib and xmltask.<br /></em>My solution for getting well-formed xml was built into Microsoft SQL Server using 'FOR XML RAW' then adding a root tag around the result. I wanted XML initially to import it by xmlproperty but found xmlproperty a little limiting. I came across xmltask which has alot of features.The meat of the post is in the code and echo statements so take a look. There is alot going on so I may break this code into simplier blocks for more emphasis on certain actions and expand on them individually.<strong>To run:</strong> simply unzip then run the build.xml. It will ask for your username, password, and database ip for Microsoft Server. And ask for which scenerio to run (A or B). A: uses xmltask and B: uses xmlproperty.NOTE: The zip contains build.xml, ant-contrib-1.0b3.jar, xmltask-v1.15.1.jar, root_end.txt, and root.txt.<strong><em>This ant runs a query, saves the results as a file,<br /> manipulates the file to be loaded as xml, <br /> And loops through the results doing other individual queries</em></strong>
