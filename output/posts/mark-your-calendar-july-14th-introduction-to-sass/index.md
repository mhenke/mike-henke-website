<div style="margin: 0px;"><span style="letter-spacing: 0px;"><strong><em>Synopsis:</em></strong></span></div>
<div style="margin: 0px;"><span style="letter-spacing: 0px;"><em>Sass has been growing in popularity since Hampton Catlin first introduced it in 2005.  Sass, which stands for Syntactically Awesome Style Sheets, helps you write less-verbose code with better organization.  </em></span></div>
<div style="margin: 0px;"><em><br /></em></div>
<div style="margin: 0px;"><span style="letter-spacing: 0px;"></span><em>Originally a Ruby technology, Sass can help organize and streamline any web application’s styling that uses CSS, including ColdFusion projects.  You’ll see what Sass has to offer, how to set it up, and how to write it.</em></div>
<div style="margin: 0px;"><span style="letter-spacing: 0px;"><em><br />Come see what Sass, and it’s new variation SCSS, can do for your styling workflow.</em></span></div>
