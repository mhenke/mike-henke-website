Similar to Nic Tunney's <span><a href="http://www.nictunney.com/index.cfm?mode=entry&amp;entry=E1E350D7-FF61-56C5-E94CA390F9B3D0F0" target="_blank"><span><span style="color: #800080;">Top 6 Underused ColdFusion Functions</span></span></a> I figured I would post an Eclipse underused shortcuts for CFEclipse users. I think it was during a CFObjective presentation by <a href="http://www.nodans.com">Dan Wilson</a>, I witnessed the copy down shortcut (ctrl-alt-down) and was impressed.</span><span>I feel many <a href="http://cfeclipse.org/">CFEclipse</a> beginners don't realize Eclipse is the real power and heart while CFEclipse harnesses it and adds features.</span><span>Here is my list of underused Eclipse shortcuts for ColdFusion users.</span><div><strong>6. Quick Switch Editor - Ctrl+E </strong></div><div><span><em>You can quickly switch editors using the <span><span>Ctrl+E</span> keybinding which opens a list of all open editors. The list supports type-ahead to find the editor as well as allows you to close editors using a popup menu or the Delete key</span></em>. </span></div><div><img src="/machblog/images/ctre.jpg" alt="" /></div><div><strong>5. Delete commands</strong></div><div>Previous word - Ctrl+backspace,</div><div>Next word - Ctrl+delete</div><div>Line - Ctrl+d</div><div>To end of line - Ctrl+Shift+delete</div><div><br /></div><div><strong>4. <span>Go to last edit location - Ctrl+Q</span></strong></div><div><span></span><em><span>Ctrl+Q</span></em><em> takes you back to the place where you last made a change.</em></div><div><br /></div><div><strong>3. Now, where was I? - Alt+Left Arrow</strong></div><div><span><em>Workbench editors keep a navigation history. If you open a second editor while you're editing, you can press Alt+Left Arrow to go back to the last editor. This makes working with several open editors a whole lot easier.</em></span></div><div><br /></div><div><strong>2. <span>Faster workspace navigation - Ctrl+Shift+R</span></strong></div><div><span><em><span>Ctrl+Shift+R</span></em></span><em> brings up a dialog that allows you to quickly locate and open an editor on any file in the workspace. In the same vein, <span>Navigate &gt; Go To &gt; Resource expands and selects the resource in the Project Explorer view itself, if it has focus.</span></em></div><div><img src="/machblog/images/ctrr.jpg" alt="" /></div><div><br /></div><div><strong>1. Quick access - <span>Ctrl+3</span></strong></div><div><em>You can quickly find all manner of contributions with the Ctrl-3 binding including (but not limited to) open editors, available perspectives, views, preferences, wizards, and commands. Simply start typing the name of the item you wish to invoke and we will attempt to find something in the Workbench that matches the provided string.</em></div><div><img src="/machblog/images/quickaccess.png" alt="" /></div><div><br /></div><div>Be sure to check out Help --&gt; Key Assist (Ctrl+Shift+L) for other shortcuts and remember the list changes depending on the editor you are in. T<span>he definitions in <em>italics </em>above are from the <a href="http://help.eclipse.org/help33/index.jsp">Eclipse Documentation</a>.</span></div>
