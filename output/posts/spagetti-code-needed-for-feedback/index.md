Majority of ColdFusion code is not testable in its current state. There I said it. Now with that out of the way, I would love you to try out my "<a href="https://github.com/mhenke/Cloudy-With-A-Chance-Of-Tests">Cloudy With A Chance Of Tests</a>" project and give this a test drive. It is to help improve the quality of your code which maybe in any state. 
Please <a href="https://github.com/mhenke/Cloudy-With-A-Chance-Of-Tests/issues">create issues</a> for any problems or clarifications needed. Currently, the compilation only works on the Adobe ColdFusion engine.
