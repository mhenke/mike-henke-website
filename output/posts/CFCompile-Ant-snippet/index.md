<p style="text-align: left">I have been working on a build.xml file for work that updates the local working copy, runs <a href="http://mxunit.org">MXunit</a> tests, create JUnit reports based on MXunit results, <a href="http://mikehenke.com/machblog//index.cfm?event=showEntry&amp;entryId=8A5CAB53-19B9-BA51-EECADB57919F9714">minifies js/css</a>, grabs only <a href="http://mikehenke.com/machblog//index.cfm?event=showEntry&amp;entryId=8D3AAA71-19B9-BA51-EEF8E251D9BE0A45">modified files between revisions</a>, <a href="http://webalfee.wordpress.com/2008/06/17/what-is-html-chrunching/">crunches</a> ColdFusion files, checks compile errors, and also will check for unscoped vars in cfcs using <a href="https://varscoper.riaforge.org/">varScoper</a>.<p style="text-align: left">Here is a snippet for the checking ColdFusion compiling using cfcompile. I'll release the full build.xml, lib, and buildprops when I have the unscoped var target working.<p style="text-align: left"> <em> &lt;!--<br /> compileCheck<br /> Compiles the ColdFusion files for any syntax errors<br /> --&gt; <br /> &lt;target name="compileCheck"&gt;<br /> &lt;echo&gt;Check Coldfusion Compile for ${webroot}${temp.dir}${jarfileTstamp}&lt;/echo&gt;<br /> <br /> &lt;exec failonerror="true" dir="${cfcompile_path}" executable="cmd.exe" output="${webroot}${temp.dir}${jarfileTstamp}compile${jarfileTstamp}.txt" &gt;<br /> &lt;env key="JAVA_HOME" value="${JAVA_HOME}"/&gt;<br /> &lt;arg line="/c cfcompile.bat ${webroot}${temp.dir}${jarfileTstamp}" /&gt;<br /> &lt;/exec&gt;<br /> &lt;!-- need to check log for failures --&gt;<br /> &lt;loadfile srcfile="${webroot}${temp.dir}${jarfileTstamp}compile${jarfileTstamp}.txt" property="src.file.cferrors"&gt;<br /> &lt;filterchain&gt;<br /> &lt;LineContainsRegExp&gt;<br /> &lt;regexp pattern="Error*"/&gt;<br /> &lt;/LineContainsRegExp&gt;<br /> &lt;/filterchain&gt; <br /> &lt;/loadfile&gt;<br /> &lt;echo&gt;${src.file.cferrors}&lt;/echo&gt;<br /> &lt;fail&gt;<br /> &lt;condition&gt;<br /> &lt;isset property="src.file.cferrors"/&gt; <br /> &lt;/condition&gt;<br /> &lt;/fail&gt; <br /> &lt;/target&gt;</em><p style="text-align: left"> <p style="text-align: left">Related Posts:<p style="text-align: left"><a href="http://www.webdevref.com/blog/index.cfm?t=Use_eclipse,_ant_and_cfcompile.bat_to_precompile_your_code&amp;mode=entry&amp;entry=79C9D104-12CC-9590-8A5C8AA23FF93A8B&amp;dv=link">Use eclipse, ant and cfcompile.bat to precompile your code</a><p style="text-align: left"><a title="Permalink to Snarling radioactive ants!" href="http://hofo.com/post.cfm/snarling-radioactive-ants">Snarling radioactive ants!</a>
