<p style="text-align: left">I will show how to setup <a href="#FDWindows">FusionDebug on Windows for Multiple ColdFusion instances</a>. And <a href="#CF8D">ColdFusion 8 Debugger on Ubuntu</a>. A hint for both is turn off "timeout request after (seconds)" in the CF Administrator so your debugging info doesn't timeout. Within Eclipse, I use the Breakpoints, Debug, Variables, and Expressions views.<p style="text-align: left"><img alt="" src="/machblog/uploads/Image/EclipseDebug.jpg" /><p style="text-align: left"> <p style="text-align: left"><a name="FDWindows">FusionDebug Windows</a><br /><br />In the Coldfusion Administrator go to the <em>"Enterprise Manager"</em> and then <em>"Instance Manager"</em>. Click "add new instance", this example we will name it <strong>FD1</strong>. <br /> <br />Check "Create Windows Service" option and <strong>create the new instance</strong>. <br /><em>** note : Coldfusion will automatically create the first instance on port 8301 and increment by one when creating a new instance. </em><br /> <br /><em><strong>Stop</strong> the newly created instance</em> through services, <em>default name for this example</em> would be <strong>"Macromedia CFMX AS FD1"</strong>. <br /> <br />Use the FusionDebug Server Configuration Wizard to create the <em>new config file</em>. This will modify the <strong>jvm.config</strong> file, but for multiple instances you will need multiple jvm.config files.<br /><br />Users of an older version of FusionDebug will have to copy and modify the jvm.config file as described in FusionDebug Guide.<br /><br />The jvm.config is in JRun4in. Change address=8000 to 8001 and <em>save as</em> new config file, with new name, example<strong> jvm.config_FD1</strong><br /> <br /><em>** note : each new CF instance will have to listen on a separate port. I like to keep my port number consistant like CF port 8301 will match up to debugging port 8001. </em><br /> <br />Next we will <em>remove the cf service</em> we created during installation, and have it <em>point to the new</em> <em>config </em>file we created.<br /><br />Open the <strong>command prompt </strong>and navigate to the bin of JRun4 then use these command:<br /> <br /><em>cd C:JRun4in <br /> <br />jrunsvc -remove "Macromedia CFMX AS wfs1" <br /> <br />jrunsvc -install wfs1 "Macromedia CFMX AS wfs1" "Macromedia CFMX AS wfs1" -config jvm.config_wfs1 </em><br /> <br />Now <strong>start the CF instance </strong>and configure the FusionDebug connection through Eclipse. Repeat this process for each instance. <p style="text-align: left">Snapshots of FusionDebug setup within Eclipse. <strong>Run --&gt; Open Debug Dialog --&gt; FusionDebug</strong><p style="text-align: left"><img alt="" src="/machblog/uploads/Image/FDC.jpg" /><p style="text-align: left"><img alt="" src="/machblog/uploads/Image/FDS.jpg" /><p style="text-align: left"> <a name="CF8D">ColdFusion 8 Debugger on Ubuntu</a><br /><br />Within ColdFusion 8 Administrator, you must <strong>turn on RDS</strong> and then <strong>specify the debugger port </strong>in the JVM settings of your application server. This example will be using port 80 for the webservice and port 8000 for debugging.<p style="text-align: left">Setting the Debugging information is located at <em>Debugging &amp; Logging --&gt; Debugger Settings</em>. Make sure the <strong>"Allow line debugging"</strong> is checked also.<p style="text-align: left"><img alt="" src="/machblog/uploads/Image/cf8admi.jpg" /><br /><br />Besides this you will need to modify the jvm.config file. Mine was located<strong> /opt/jrun4/bin</strong>. I added<br />to the "Arguments to VM" section: <em>-Xdebug -Xrunjdwp:transport=dt_socket,server=y,suspend=n,address=8000</em>, and restart the server. <p style="text-align: left"><strong>Be extra carefull with spaces and returns.</strong><br /><br />Full Example of section:<br /><em># Arguments to VM<br />java.args=-server -Xmx512m -Dsun.io.useCanonCaches=false -XX:MaxPermSize=192m -Djava.awt.headless=true -Dcoldfusion.rootDir={application.home}/ -Djava.compiler=NONE -Xnoagent -Xdebug -Xrunjdwp:transport=dt_socket,server=y,suspend=n,address=8000</em><br /><br />Now restart ColdFusion and you should be good ready to configure Eclipse.<br /><br />You will need to configure two seperate settings for CF8 Debugger.<br /><br />First is the <em>Windows --&gt; Preferences --&gt; ColdFusion --&gt; RDS Configuration</em><p style="text-align: left"><img alt="" src="/machblog/uploads/Image/cf8EclipsePrefj.jpg" /><p style="text-align: left"><br />Second is<em> Run --&gt; Open Debug Dialog</em>. Add a new ColdFusion Application.<p style="text-align: left"><img alt="" src="/machblog/uploads/Image/cf8EclipseDebug.jpg" />
