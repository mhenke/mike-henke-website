I enjoy listening to <a href="http://www.halhelms.com/">Hal Helms</a> and he recently was on an <a href="http://www.engineyard.com/">Engine Yard</a> podcast, <a href="http://www.engineyard.com/podcasts">Cloud Out Loud</a>. He brings a thought provoking perspective to discussions. He learned a new skillset, <a href="http://rubyonrails.org/">Ruby on Rails</a>, after being a long time <a href="http://en.wikipedia.org/wiki/ColdFusion">ColdFusion</a> programmer. <a href="http://www.engineyard.com/podcast/s01e37-hal-helms">The podcast is definately worth listening to</a> and is just over 15 minutes. I wish he would have mentioned ColdFusion is not only <a href="http://www.adobe.com/products/coldfusion-family.html">Adobe</a> but does have open source options like <a href="http://www.getrailo.com/">Railo</a> and <a href="http://www.openbluedragon.org/">OpenBD</a> during the open source discussion. The ACF long release cycle is a thought provoking point compared to quick release cylce software especially these days when technology advances and changes so fast. Also a mention of <a href="http://www.cfwheels.org">ColdFusion on Wheels</a>, a framework based on Rails, would have been awesome.
