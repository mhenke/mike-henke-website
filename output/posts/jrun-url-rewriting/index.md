I was working on my next installment of "<a href="/wheels-series/">So you want to create a CFWheels application?</a>" and was able to easily get URL Rewriting on JRun which I thought was previously not available.I used the <a href="http://tuckey.org/urlrewrite/">Url Rewrite Filter</a> mentioned by <a href="http://www.mattwoodward.com">Matt Woodward</a> in his "<a href="http://www.mattwoodward.com/blog/index.cfm?event=showEntry&amp;entryId=60F08421-5F0A-41C9-940B3681A3D09D99">Open BlueDragon + Railo + ColdFusion on Tomcat</a>" blog entry. It was very simple to setup since the instructions are well written and seemed straightfoward for the URL Rewrite Filter. I was also able to copy some Apache rewriting rules already setup in <a href="http://www.cfwheels.org">CFWheels</a>.
