I finally went through the <a href="http://bittersweetryan.github.com/ColdFusion-Koans/">ColdFusion Koans</a> (CFK) a couple weekends ago. It was a great experience. I learned more about CFML along with <a href="http://mxunit.org">MXUnit</a>.
<a href="http://blog.bittersweetryan.com/">Ryan Anklam</a> and the <a href="http://coldfusionshow.com/">ColdFusion Show</a> are extending a contest for an <a href="http://www.coldfusionormbook.com/">ColdFusion ORM</a> ebook.
<ul>
<li><a href="http://www.coldfusionormbook.com/">ColdFusion ORM book</a> (electronic) from <a href="http://bittersweetryan.github.com/ColdFusion-Koans/">ColdFusion Koans</a><ol>
<li>take picture/screenshot of finished Koans then leave comment on <a href="http://coldfusionshow.com/post.cfm/episode-7-contests-acf10-beta-code-school-angelina-jolie-s-leg-1">this blog post</a> with link to picture <strong><em>OR</em></strong></li>
<li>contribute to <a href="https://github.com/bittersweetryan/ColdFusion-Koans">ColdFusion Koans project on github</a></li>
</ol></li>
</ul>
Basically, complete the koans, snap a picture and upload it to google plus, any of the many twitter picture hosting sites, or some place else then <a href="http://coldfusionshow.com/post.cfm/episode-7-contests-acf10-beta-code-school-angelina-jolie-s-leg-1">comment on the latest eposide of the ColdFusion Show</a> with a link to the picture. You could do a screenshoot also. The winner for the ORM ebook will be randomly selected from entries.
Another way is to help with the Koans project. Fix a typo, add a test, fix a ticket - anything is encouraged small or large.
Here is a testimonial from a co-worker. Nic is a network admin and wanted to learn a little bit more about ColdFusion servers and CFML programming since he is supporting the infrastructure. I pointed him to <a href="https://github.com/mhenke/CFML-in-100-minutes">CFML in 100 mins</a> and the CFK project. He emailed me this after completing the CFK:
<em>Mike<br /><br />CFK was a <strong>very informative set of lessons</strong>; there are two of them which I don't completely understand. I'm going to shoot through CFML in 100 minutes tonight so I should be good to go for tomorrow.<br /><br />Thanks,<br /><br />Nic</em>
