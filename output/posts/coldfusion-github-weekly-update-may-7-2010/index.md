<a href="http://en.wikipedia.org/wiki/ColdFusion">ColdFusion</a> is hanging steady at the 29th most popular language on <a href="http://github.com/">Github</a>. Big news on the ColdFusion/Github front is <a href="https://fw1.riaforge.org/">FW/1</a>. I didn't catch an official announcement but it seems <a href="http://github.com/seancorfield/fw1">FW/1 is using github</a> for their central code repository/site. Github's ticket system is setup and allowing <a href="http://github.com/seancorfield/fw1/issues">people to submit and vote on tickets</a> and they started using <a href="http://wiki.github.com/seancorfield/fw1/">Github's wiki feature</a>. Check out <a href="http://github.com/seancorfield/fw1/graphs/punch_card">the punch card to see when Sean</a> and the crew are working their hardest. Github announced a <a href="http://github.com/blog/646-redesigned-repository-admin-screens">redesign of their admin screens</a> and <a href="http://github.com/blog/644-subversion-write-support">Subversion write support</a>. With that said here are the movers and shakers for last week on Github.
