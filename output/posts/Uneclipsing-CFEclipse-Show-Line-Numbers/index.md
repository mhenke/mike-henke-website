Quick Eclipse and CFEclipse hint. The entry is mainly about<em> turning on CFEclipse line numbers</em> but <em>useful for other hidden Eclipse preferences.</em>In Eclipse, under<strong> Windows --&gt; Preferences</strong> are many settings its hard to locate the one you are looking for. Eclipse actually has a built in search/filter. In my screenshot I start typing in "numbers" since I am looking for turning on line numbers. I could look for font, startup, etc. All the preferences filter so only matching settings are left.<img width="480" height="576" alt="" src="/machblog/uploads/Image/GenEditor.jpg" />You might think you have turned on Line numbers for CFEclipse but actually it is for Eclipse. You will need to switch on<em> a line number setting specific for CFEclipse</em>. This setting actually doesn't work for the filter but my last screen shot shows were it is located. Restart any open CFEclipse files and now the line numbers should appear.<img width="480" height="561" alt="CFEclipse Line Number setting" src="/machblog/uploads/Image/CFEclipsePref.jpg" />
