I would like to thank <a href="http://cfobjective.com">cf.Objective()</a> for accepting my submission for a session over <a href="http://cfwheels.org">ColdFuson on Wheels</a>.
<a href="http://cfobjective.com"><img src="/assets/content/CFObjective_09_banner_468x62.jpg" alt="" width="229" height="35" /></a>
cf.Objective() 2010: April 22-24, 2010 at the Hyatt Regency Minneapolis, MN <a href="https://www.bestmeetings.com/registration/cfobjective/cfobjective.cfm">Registration</a>
Title: ColdFusion on Wheels, Inspired by Ruby on Rails
Description: Inspired by <a href="http://rubyonrails.org">Ruby on Rails</a>, ColdFusion on Wheels provides <a href="http://en.wikipedia.org/wiki/ColdFusion_Markup_Language">CFML</a> developers with a rapid <a href="http://en.wikipedia.org/wiki/Model%E2%80%93view%E2%80%93controller">MVC</a> framework for increased productivity, organized code. We'll be showing the development workflow for CFWheels starting with the basics and ending with more advanced techniques.
Audience: Anyone looking for a MVC framework that works like ColdFusion developers for rapid, easy development.
