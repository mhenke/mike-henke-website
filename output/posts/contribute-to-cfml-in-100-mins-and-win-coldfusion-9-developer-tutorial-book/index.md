Time for another Contribute and Win contest. This will be the third <a href="/blog/contribute-win-a-chance-for-object-oriented-programming/">Contribute and Win</a>. Contribute and win has had many simple and more complex contributes from various developers. Same rules as before, I will randomly select a contributor to "<a href="https://github.com/mhenke/CFML-in-100-minutes">CFML in 100 minutes</a>" and award them the prize. You can commit once or multiple times but you will only be entered in once. I will giveaway a copy of "<a href="http://www.amazon.com/ColdFusion-Developer-Tutorial-John-Farrar/dp/1849690243/ref=sr_1_6?ie=UTF8&amp;qid=1326471081&amp;sr=8-6">ColdFusion 9 Developer Tutorial</a>" to lucky contributor of "<a href="https://github.com/mhenke/CFML-in-100-minutes">CFML in 100 minutes</a>". The winner will be announce on Jan 31, 2012.
<h3>Spot a typo or code example not working</h3>
All you need is an eagle eye to spot a typo or code example not working. 
<h3>Fix a ticket<br /></h3>
<a href="https://github.com/mhenke/CFML-in-100-minutes/issues">Grab a ticket</a>, fix it, then submit a pull request.
<h3>Add script examples<br /></h3>
Want practice with script, look at a tag example and port it to script.
<h3>Contributing is dead simple</h3>
Contributing is <em>dead simple</em>, log into <a href="http://www.github.com/">Github</a> then click "<a href="https://github.com/blog/844-forking-with-the-edit-button">Fork and edit this file</a>" button on the <a href="https://github.com/mhenke/CFML-in-100-minutes/blob/develop/cfml100mins.markdown">cfml100mins.markdown</a>
 file. That will automatically fork the project so you can edit the file
 in the browser. Once your edit is complete send me a pull request via 
Github and you are entered into the giveaway.
