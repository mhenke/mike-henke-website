Adobe announced public beta for their second release of an IDE based on <a href="http://www.eclipse.org">Eclipse</a> which enables developers to rapidly build, deploy, and maintain robust Internet applications for the enterprise.
"The new beta release provides professional coding tools, server 
      management, testing tools, and new deployment capabilities, enabling 
      developers to quickly and easily move from development to production 
      with less code and fewer errors." - <a href="http://www.tradershuddle.com/20110303177511/Press-Releases/Adobe-ColdFusion-Builder-2-Public-Beta-Now-Available.html">Press Release</a>
The first release "had many useful features such as syntax highlighting, Syntax Checking, Code Assist, code outline, code folding, project management, RDS and FTP support, debugger, server manager, and extensions." In this public beta release, Adobe has "enhanced many of these features and added many new features." This <a href="http://www.adobe.com/devnet/coldfusion/articles/cfb2-whatsnew.html">"What's New" article</a> covers the all the new features and enhancements for <a href="http://www.adobe.com/products/coldfusion/cfbuilder/features/">ColdFusion Builder</a>.
The Eclipse-based IDE for <a href="http://www.adobe.com/products/coldfusion/">ColdFusion</a> application development can be <a href="http://labs.adobe.com/technologies/coldfusionbuilder2/">download from Adobe Labs</a>.
