I will be switching the <a href="http://www.github.com">Github</a> &amp; ColdFusion Weekly Update to Sunday so I don't miss any activity during the weekend. Some noteworthy events: <a href="http://github.com/tpryan">Terrence Ryan</a>, Platform Evangelist for Adobe, opened a Github account and has been very busy starting four repositories. <a href="http://github.com/virtix">Bill Shelton</a> created a respotiory for <a href="http://github.com/virtix/mxunit">MXUnit</a>. Github introduced a <a href="http://github.com/blog/612-introducing-github-compare-view">compare view</a>. <a href="http://github.com/russjohnson">Russ Johnson</a> helped contribute to the <a href="http://cfwheels.org/plugins/listing/9">Wheels Scaffolding plugin</a>.
