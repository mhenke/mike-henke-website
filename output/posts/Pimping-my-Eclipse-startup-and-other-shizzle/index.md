A couple weeks ago when writing the entry, <a target="_self" href="http://mikehenke.com/machblog/index.cfm?event=showEntry&amp;entryId=FA78BD3D-188B-4E84-15C225362B1283AB">UnEclipsing CFEclipse Line Numbers</a>, I stumbled on a couple interesting settings in preferences to pimp my Eclipse EDI <img src="/machblog//FCKeditor/editor/images/smiley/msn/teeth_smile.gif" alt="" /><br /><br />On the net is plenty of info for tweaking eclipse.ini file or adding variables to eclipse executable for performance but I hadn't seen anything about the settings below.<h3>Plug-ins activated on startup</h3><em>Windows --&gt; Preferences</em> then type <strong>"startup"</strong> in filter or navigate to <em>General --&gt; Startup and Shutdown</em>. The settings I found interesting were "Refresh workspace on startup" and "Plug-ins activated on startup". I unchecked all plugins I don't use like Eclipse Monkey and most Aptana plugins.<h3>Always run in background</h3><em>Windows --&gt; Preferences</em> then type <strong>"background"</strong> in the filter or navigate to <em>General.</em> I toggled on "Show heap status" and "Always run in background". Not really a performance tweak but will allow processes not to bring my use of Eclipse to a halt. And I can easily see my heap size in case I need to modify it.<h3>Workspace</h3><em>Windows --&gt; Preferences --&gt; General --&gt; Workspace</em>. I checked Build, Refresh, and Save automatically. This is more for builds but Refresh automatically does run every so often.<h3>Aptana Start page</h3>Windows --&gt; Preferences then type <strong>"start page"</strong> in the filter or navigate to Aptana --&gt; Start Page. I set the option to "Never display after startup". No more annoying Aptana splash page. I read people complaining Aptana taking over Eclipse and I noticed it becoming more intrusive also. This change and the next below should help.<h3>Automatic Updates</h3><em>Windows --&gt; Preferences --&gt; Aptana --&gt; Updates</em>, you could shut off the options to improve startup, but I have Aptana find new updates and download automatically checked on. I do the same with general Eclipse plugins under <em>Windows --&gt; Preferences --&gt; Install/Update</em>. I check "Automatically select mirrors" under <em>Install/Update --&gt; Automatically Updates</em> and I specify "look for updates" every Monday and again download automatically.<h3>SVN Menu Icon</h3>Nothing to do with performance but a cool setting I didn't know existed. <em>Windows --&gt; Preferences --&gt; Team --&gt; SVN --&gt; Menu Icons</em>, you can set icons Eclipse uses for Subversion. My options were default, TortoiseSVN, or Subversion. Very neat.
