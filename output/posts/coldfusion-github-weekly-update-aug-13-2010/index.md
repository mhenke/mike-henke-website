It has been over a <em>busy</em> month since the last <a href="http://www.adobe.com/products/coldfusion/">ColdFusion</a> and <a href="http://www.github.com">Github</a> update. A lot has transpired. 
 
CFUnited's keynote by <a href="http://www.adrocknaphobia.com">Adam Lehman</a> and <a href="http://www.terrenceryan.com/">Terry Ryan</a>, highlighted Github adding ColdFusion as a language for one of the numerous ColdFusion highlights over the last year. Terry demo-ed and announced <a href="http://github.com/tpryan/Apptacular">Apptacular</a> on github. Apptacular is a <a href="http://www.adobe.com/products/coldfusion/cfbuilder/features/">ColdFusion Builder</a> Extension for scaffolding applications straight from the database.
 
Several projects announced they are on Github: <a href="http://kisdigital.wordpress.com/2010/07/12/cfmud-is-now-up-at-github/">cfMud is now up at GitHub</a>, <a href="http://www.mischefamily.com/nathan/index.cfm/2010/7/28/WebSockets-with-ColdFusion">WebSockets with ColdFusion</a>, and <a href="http://iamjamesgibson.com/weblog/item/cfwheels-assetbunder-10-released">CFWheels Assetbunder 1.0 Released</a>!
 
It was blogged <a href="http://thediscoblog.com/2010/08/13/guidance-on-git-podcast/">IBM DeveloperWorks is starting a podcast and their first release is over git</a>.
 
Github is <a href="http://github.com/blog/699-making-github-more-open-git-backed-wikis">enhancing their wiki</a>. I think using Github for coding tutorials will see a rise by creating branches and wiki pages for walkthroughs. This will allow others to contribute and clarify tutorials.
 
Github hit <a href="http://github.com/blog/685-one-million-repositories">One Million repositories</a>.  
 
<a href="http://www.meetup.com/coldfusionmeetup/">CFMeetup</a> will have a session over Git next week.
 
Now the movers and shakers on Github for ColdFusion projects.
