Time for another Contribute and Win contest. The last <a href="/blog/contribute-win-a-chance-for-object-oriented-programming/">Contribute and Win</a> seemed a great success. I had many awesome contributes. Same rules as before, I will randomly select a contributor to "<a href="https://github.com/mhenke/CFML-in-100-minutes">CFML in 100 minutes</a>". You can commit once or multiple times but you will only be entered in once. I will giveaway a copy of "<a href="http://www.amazon.com/gp/product/1449393217">Head First jQuery</a>" to lucky contributor of "<a href="https://github.com/mhenke/CFML-in-100-minutes">CFML in 100 minutes</a>".
<h3>Spot a typo or code example not working</h3>
All you need is an eagle eye to spot a typo or code example not working. If you are more ambitious, <a href="https://github.com/mhenke/CFML-in-100-minutes/issues">grab a ticket</a> or create another example or section. I will announce the winner Tuesday, Oct 13th.
<h3>Contributing is dead simple</h3>
Contributing is dead simple, log into <a href="http://www.github.com/">Github</a> then click "<a href="https://github.com/blog/844-forking-with-the-edit-button">Fork and edit this file</a>" button on the <a href="https://github.com/mhenke/CFML-in-100-minutes/blob/develop/cfml100mins.markdown">cfml100mins.markdown</a>
 file. That will automatically fork the project so you can edit the file
 in the browser. Once your edit is complete send me a pull request via 
Github and you are entered into the giveaway.
