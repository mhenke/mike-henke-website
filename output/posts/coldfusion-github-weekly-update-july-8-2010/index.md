This week in <a href="http://en.wikipedia.org/wiki/ColdFusion">ColdFusion</a> and <a href="http://github.com">Github</a> news: Github is asking for <a href="http://github.com/blog/671-do-you-use-git-on-windows">input from users using windows</a>. It is a short survey. There is an online upcoming event July 13th, covering <a href="http://live.eclipse.org/node/930">egit and Eclipse</a>. This would also pertain to users of <a href="http://www.adobe.com/products/coldfusion/cfbuilder/features/">CFBuilder</a> and <a href="http://www.cfeclipse.org/">CFEclipse</a> naturally. Mr. Corfield <a href="http://corfield.org/blog/post.cfm/fw-1-hotfixes-for-1-0-and-1-1">mentions adopting a workflow</a> for <a href="http://github.com/seancorfield/fw1">FW/1</a> on github. Adam Tuttle blogged about <a href="http://fusiongrokker.com/post/easily-ignore-cfbuilder-meta-files-in-a-new-git-repo">Easily Ignore CFBuilder Meta Files in a new Git Repo</a>.  Rob Williams talks about a <a href="http://www.jroller.com/robwilliams/entry/super_quick_git_setup_guide">Super Quick Git Setup Guide for OS/X</a>. Finaly, here are several git basic blog posts this past weeek, <a href="http://brandonwamboldt.ca/2010/07/git-and-updates/">Git and updates</a>, <a href="http://en.saturngod.net/blogpost/using-git">Using Git</a>, and <a href="http://java.dzone.com/news/working-branches-git">Working with Branches in Git</a>.
