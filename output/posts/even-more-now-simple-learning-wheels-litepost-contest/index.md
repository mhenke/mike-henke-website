ColdFusion On Wheels <a href="http://cfwheels.org/blog/index.cfm/2010/1/25/Wheels-LitePost-Contest--win-Amazon-Gift-Card">announced a contest</a> to create an example of <a href="http://en.wikipedia.org/wiki/LitePost_%28blogging_application%29">LitePost</a>
 using Wheels. LitePost is a simple blogging application used to demonstrate different ColdFusion frameworks implementations like <a href="http://www.fusebox.org">Fusebox</a>, <a href="http://www.mach-ii.com">Mach-II</a>, <a href="http://docs.model-glue.com">Model-Glue</a>, and <a href="http://www.coldboxframework.com">ColdBox</a>. Shortly after being posted, two other donations came in. Now the prizes are $100 and two $50 Amazon Gift Cards.
