I finally had the chance to use the <a href="https://uu2.riaforge.org/">Unofficial Updater 2</a> (uu2) by <a href="http://www.dcepler.net">David Epler</a>. I must say it is pretty AWEsome.
<em>Being a user and not reading</em>, I scanned the readme file in the github repository, then tried using it. Big mistake. Be sure to look at the revamped <a href="https://github.com/dcepler/unofficial-updater2/blob/master/README">readme</a> with a "How to Use" section and the <a href="https://github.com/dcepler/unofficial-updater2/wiki/Using-Unofficial-Updater-2">wiki</a>. That being said, it is pretty easy once I overcame two issue. 
The first big issue was I missed the <a href="https://github.com/dcepler/unofficial-updater2/wiki/Using-Unofficial-Updater-2">wiki</a> so was trying to run the jar by clicking on it which gave a <em>tools.jar error</em>. You need to run the jar via the command prompt with "<em><strong>java -jar Unofficial-Updator2.jar</strong></em>" if you get this error.
Second issue, <em>my scanning of readme wasn't good</em> so be sure your Adobe ColdFusion (ACF) servers are at least <em><strong>8.0.1</strong></em> or <em><strong>9.0.1</strong></em>.
Once user-stupidity was overcame, I think uu2 is very useful.
Check the <a href="https://github.com/dcepler/unofficial-updater2/wiki/Using-Unofficial-Updater-2">wiki for screenshots</a>.
