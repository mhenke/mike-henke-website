I will show how to switch a <a href="http://www.riaforge.com">Riaforge</a> project using <a href="http://en.wikipedia.org/wiki/Subversion_%28software%29">SVN</a> to use <a href="http://en.wikipedia.org/wiki/Git_(software)">Git</a> and <a href="http://github.com/">Github</a>.Git is more geared for open source projects since it easily allowscontributes from anyone. A hierarchy might eventually evolve where theproject owner watches four of his trusted friends, then those four mightwatch a couple other repositories, and changes from the bottom filterup. Confused yet? Don'tworry, we will work through this process with a RiaForge project.Another useful case is the orginal project creator, has moved on to other things so the project isn't advancing. Somedevelopers maybe working on the project but no way to commit thechanges. Git would allow people to see the project fork and the activerepository may become where people will start going to pulling from.First,we will install <a href="http://code.google.com/p/msysgit/">msysygit</a>, <a href="http://code.google.com/p/tortoisegit/">tortoisegit </a>(a port of <a href="http://tortoisesvn.tigris.org/">tortoisesvn</a>), and <a href="http://git.or.cz/gitwiki/EclipsePlugin">EGit</a>, an Eclipse plugin. Then, we will setup a free Github account,create a Git repository for our Riaforge project, import our SVNrepository, and then change the Riaforge settings to show our newrepository. After that we can show how the scenerios I mentioned abovemay work.Iam on a Vista laptop. I downloaded the full installer from msysgit(Git-1.6.4-preview20090730.exe) and installed it. I clicked through thedefault until this screen and unchecked the top two options.<img src="http://mikehenke.com/assets/content//1_1.jpg" alt="" width="640" height="400" />The next series of slides will show when I diverted from the default settings.<img src="http://mikehenke.com/assets/content//1_2.jpg" alt="" width="640" height="400" /><img src="http://mikehenke.com/assets/content//1_3.jpg" alt="" width="640" height="400" /><img src="http://mikehenke.com/assets/content//1_4.jpg" alt="" width="640" height="400" />There, installed msysgit and nothing smoking yet. We can take a deep sigh of relief.<br /><br />Well, lets tackle <a href="http://code.google.com/p/tortoisegit/">tortiosegit</a>.Navigate to the download page, and select the appropriate file for your system. Iselected TortoiseGit-0.9.1.0-64bit.msi since my laptop is 64bit. Thisinstallation wizard is a lot less threating. Just a couple clicks andfinished.<img src="http://mikehenke.com/assets/content//1_5.jpg" alt="" width="640" height="400" /><br />You thought we were out of thewoods, but the installer will ask you to reboot. This is for the iconsso we can skip rebooting for now.<br /><br />Next for the Eclipse plugin, go to <a href="http://git.or.cz/gitwiki/EclipsePlugin">Egit</a>'s home page. You should see an update sitefor the plugin and copy it. Start your Eclipse. I will be using<a href="http://labs.adobe.com/technologies/coldfusionbuilder/">ColdFusion Builder's beta</a>. Once started, select Help from the menu andthen "Software Updates". Click "Add Site", the paste in the updatesite url, and select "Ok."<br /><br />You will see the url in the wizard window, select the two items I have below then press "Install..." And finish out the wizard.<img src="http://mikehenke.com/assets/content//1_6.jpg" alt="" width="640" height="400" />Reboot your system, then open the command prompt and type in "git --version".<img src="http://mikehenke.com/assets/content//git1_7.jpg" alt="" width="640" height="400" />Success!! Congratulations you are your way to being a Git expert and helping advance ColdFusion Open Source projects.GitHub's <a href="http://github.com/guides/home">docs</a> is a great start if you want to read more on using Git and GitHub. <a href="http://www.ibm.com/developerworks/search/searchResults.jsp?searchType=1&amp;searchSite=dW&amp;searchScope=dW&amp;query=git&amp;Search=Search">IBM's developerWorks also has several articles about Git</a>.
