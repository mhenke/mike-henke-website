<a href="http://en.wikipedia.org/wiki/ColdFusion_Markup_Language">ColdFusion</a> moved up another spot in the <a href="http://github.com">Github</a> Language popularity to 29th. I am hoping the momentum keeps up. Github <a href="http://github.com/blog/620-committing-like-crazy">announced it has a commit about every second</a> compared to Google Code which has a commit about every 5 seconds. 
No forking again for ColdFusion. This maybe the CF Community still wrapping its head around <a href="http://git-scm.com/">git</a> and github so I'll give the most forked overall instead of this week. A nice feature of github is the <a href="http://github.com/blog/270-the-fork-queue">forking queue</a> to track any work on the project upstream. 
I noticed <a href="http://github.com/cfeclipse">CFEclipse</a> has a github account and started following it. Here is a link to see who I am <a href="http://github.com/mhenke/following">following</a>, if you aren't on it let me know.
