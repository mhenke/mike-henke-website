Adobe MAX 2008 Top Ten List - Announcements
10. In the dramatic opening session, the key speaker announces Adobe will save 15% by switching their insurance to GEICO.
9. Ben Forta, <a href="http://www.adobe.com/">Adobe Systems Inc's</a> Senior Technical Evangelist, says<span class="copy"> he'll be on next season's "Dancing With The Stars" -- this guy will do anything :-)<br />
</span>
8. Ben Forta announces Adobe has created an <a href="http://aws.amazon.com/ec2/#os">Amazon Machine Image</a> (AMI) of ColdFusion like <a href="http://developer.amazonwebservices.com/connect/entry!default.jspa?categoryID=101&amp;externalID=1716&amp;fromSearchPage=true">Railo's</a> for Amazon Elastic Compute Cloud (Amazon <span class="caps">EC2</span>). Adobe will implemented a pricing structure similar to <a href="http://aws.amazon.com/ec2/#pricing">Amazon EC2's pricing</a>.
7. Adobe announces it's plan to fix the economy: Buy more Adobe products.
6. Jason Delmore, the Product Manager for ColdFusion, hints ColdFusion will leverage Java code coverage tools for developers (maybe <a href="http://cobertura.sourceforge.net/">Cobertura</a> or <a href="http://emma.sourceforge.net/">EMMA</a>) in the next release. The ColdFusion coverage reports will be produced in a number of ways and even an Eclipse plugin to get directly to the code mentioned in the report.
5. Another new feature, similar to <a href="http://en.wikipedia.org/wiki/Seaside_(software)">Seaside</a> during development mode, you will be able to<a href="http://en.wikipedia.org/wiki/Seaside_(software)#cite_ref-4"> debug/code from within the browser</a>.
4. Raymond Camden during a BOF accidentally spoils Battlestar Galactica's final 10 episodes.
