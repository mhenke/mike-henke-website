<a href="http://en.wikipedia.org/wiki/ColdFusion">ColdFusion</a> is still the #29 most popular language on <a href="http://www.GitHub.com">GitHub</a> after several weeks of steadily moving up.
Big news this week was the release of <a href="http://www.adobe.com/products/coldfusion/cfbuilder/features/">ColdFusion Builder</a>. I would expect to see more CFBuilder extensions using Github like <a href="http://github.com/tpryan">Terrence Ryan</a>, a Platform Evangelist for Adobe. He has several available: <a href="http://github.com/tpryan/BuilderStats">BuilderStats</a>, <a href="http://github.com/tpryan/TRORM">TRORM</a>, and <a href="http://github.com/tpryan/Builder-Extension-Test-Creator">Builder-Extension-Test-Creator</a>. This means anyone can help contribute back to Terry's work by forking the repository and sending him a pull request.
I threw in "Most Watched This Month" and "Most Watched Overall" . Think of <a href="/blog/think-of-github-as-facebook-for-coders/">Github as Facebook for Coder</a>. There is even an iPhone App, <a href="http://dbloete.github.com/ioctocat/">iOctocat</a>, similiar to the Facebook iPhone App.
Finally thanks for the mention on <a href="http://www.remotesynthesis.com/archives.cfm/category/open-source-cf">ColdFusion Open Source Update </a>which is devoted to tracking all ColdFusion Open Source news.
