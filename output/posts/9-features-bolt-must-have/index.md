This list is features I feel are very important for a ColdFusion IDE.<br /> <br /> <span style="font-size: medium;">1. Mylyn Bridge</span>I use <a href="http://www.eclipse.org/mylyn/">Mylyn </a>daily for work because it helps me multitask and track my time. Currently for ColdFusion files in <a href="http://www.cfeclipse.org/">CFEclipse</a>, Mylyn is defaulted to a file view which is nice, but <a href="http://labs.adobe.com/wiki/index.php/Bolt">Bolt </a>needs to have a bridge to get even more out of the Mylyn. See the statement below for more of detail. Also the new bug/issue tracker for Bolt/Centuar needs to have a connector to Mylyn for easy entry of ideas and bugs for Bolt through Eclipse."Mylyn requires a bridge to all the tools and languages you work with (such as Ruby and JSPs). If you lack a bridge specific to the programming language or other file type that you work with, Mylyn still provides focusing down to the file level .... but won't have the fine-grained declaration filtering (for example, in the Outline view), the automatic folding of declarations in the editor, or  advanced features such as task Context Test Suites." <a href="http://www.ibm.com/developerworks/java/library/j-mylyn2/">more </a><br /> <span style="font-size: medium;">2. ColdFusion </span><span style="font-size: medium;">Explorer similar to Ruby Explorer</span>The default Navigator view and Outline view is nice but Bolt needs to take it a step further by combining the views into a ColdFusion Explorer view similiar to the Ruby Explorer view from <a href="http://www.aptana.com/rails">RadRails</a>. Single-click an element in Outline view or Ruby Explorer will take you to the line of code within the file.
