This last weekend I decided to upgrade my laptop from Vista to <a href="http://www.xubuntu.org/">Xubuntu</a>. I was tired of Microsoft's ever growing system bloat. I did install <a href="http://lubuntu.net/">Lubuntu</a> but decided to go with Xubuntu due to some panel/toolbar issues. I use this laptop for programming, listening to podcasts, watching Hulu, Amazon Unbox, and other videos. I have multiple monitors (large monitor for videos along with the laptop screen). <h2>Lightweight solution</h2>
I'll list Xubutun's current (11.04) requirements and then show Window's ever growing minimual requirements from Vista to Windows 7. My system is 2 @ 2 gigahertz processors, 6 gigabyte RAM, and 320 gigabyte disk space.
<h2 style="font-size: 1.5em; ">Xubuntu system requirements</h2>
If you want to run Xubuntu on your PC, here's what it takes:
<ul>
<li>700 megahertz x86 processor</li>
<li>192 megabyte RAM, but 256 MB RAM is strongly recommended</li>
<li>2GB gigabyte disk space</li>
</ul>
<a href="https://help.ubuntu.com/community/Installation/SystemRequirements">https://help.ubuntu.com/community/Installation/SystemRequirements</a>
<h2>Windows XP system requirements</h2>
If you want to run Windows XP on your PC, here's what it takes:
<ul>
<li>300 megahertz processor</li>
<li>64 megabytes (MB) of RAM (128 MB is recommended)</li>
<li>1.5 gigabytes disk space</li>
</ul>
<h2>Windows Vista system requirements</h2>
If you want to run Windows Vista on your PC, here's what it takes:
<ul>
<li>1 gigahertz processor</li>
<li>1 gigabyte RAM</li>
<li>40 gigabyte hard drive with at least 15 gigabyte</li>
</ul>
<h2>Windows 7 system requirements</h2>
If you want to run Windows 7 on your PC, here's what it takes:
<ul>
<li>1 gigahertz processor</li>
<li>1 (32-bit) or 2 (64-bit) gigabyte RAM</li>
<li>16 (32-bit) or 20 GB (64-bit) gigabyte available hard disk space</li>
</ul>
